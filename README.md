# Ananda Yoga Studio — CIA 2 Project

A responsive online yoga business website built using HTML, CSS and vanilla JavaScript.

## Included assignment requirements
- Home page and business introduction
- Asana, Pranayama, Kriya, Meditation and Karma Yoga Philosophy programs
- Sample prices for each program
- Contact/enquiry form with program selection
- Responsive navigation and mobile-friendly layout
- Free hosting instructions for GitHub Pages and Netlify

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. For a local development server, open a terminal in this folder and run:
   `python3 -m http.server 8000`
4. Visit `http://localhost:8000`.

## Important before submission
- Replace `hello@anandayoga.example` in `index.html` and `script.js` with an email address you control.
- The prices and studio name are sample project content. Edit them if your instructor expects your own business name/details.
- The enquiry form uses a `mailto:` link. It opens the visitor's email application and does not store submissions or process payments.
- Images and Google Fonts are loaded from external services, so internet access is needed for those assets.

## Host free using GitHub Pages
1. Sign in to GitHub and create a new public repository, for example `ananda-yoga-website`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then click **Save**.
6. Wait for deployment and copy the published URL shown in Settings → Pages.
7. Open the live URL on a phone and laptop to test it before submitting.

## Alternative: Netlify
1. Sign in to Netlify.
2. Choose **Add new site / Deploy manually** (wording may vary).
3. Drag the extracted project folder into the deployment area.
4. Copy the generated live website URL and test it.
